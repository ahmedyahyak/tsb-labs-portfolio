## How we work

1. **One fixed price, staged payments.** The build is one agreed number, split into stages.
2. **Acceptance by demonstration.** A stage is done when you watch it work, not when a document says so.
3. **Plain language agreements.** Three pages you can read without a lawyer.
4. **The founder delivers.** You deal directly with the person responsible for the build.

After delivery: run it yourself, or keep us on a monthly retainer and we run the system fully from day one, hosting, security, monitoring, support and continuous development.

## Stack

Deliberately simple: a single static page, hand written HTML, CSS and vanilla JavaScript. No framework, no build step, deployed on Vercel. Interactive details include a scroll progress bar, cursor spotlight cards, an animated system diagram, staggered reveals and full reduced motion support. Structured data included for search.

The brand system lives in [`/brand`](https://tsb-labs-portfolio.vercel.app/brand/) with downloadable SVG logo assets in [`/assets`](assets/).
